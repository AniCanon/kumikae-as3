# A frame of Empty, MoveNodes, PerNodeProcess, SignalTraffic, NBody, Sieve, Saxpy, Shapes and Alloc leaves
# nothing: what MoveNodes and PerNodeProcess count is their start, three for each of 20,000 nodes made (the
# node, its place among the children, a Number as Godot's integer) and two, and what SignalTraffic counts is
# its signal made and its listener added. The others still ask in every frame: RayQueries the query, isEmpty
# and the element for each ray; ArrayConversion the collections handed over. A number that grows is a fast
# path lost.

# PerNodeProcess: a node's handle is copied by the host once, the first time it is shared (the host looks
# at what it is on), and the object behind it is asked for twice, after which it is read from the handle
# for as long as Godot frees nothing the host has found.
