# What each frame benchmark, as native code, leaves to the library in its start and three frames
# (native_godot.py): thunks, and the places the whole program asks Godot that the host could not work out.
# A frame of Empty, MoveNodes, PerNodeProcess, SignalTraffic, NBody, Sieve, Saxpy, Shapes and Alloc leaves
# nothing. MoveNodes counts construction and integer conversion at startup. PerNodeProcess counts
# the owner of each script node added at startup. SignalTraffic counts
# its signal made and its listener added. A frame of RayQueries leaves two: the space of the world
# and the zero a Vector2 variable starts at. Nothing is left for a ray: its query is
# Godot's method called on the objects themselves, what it gives is made where its handle keeps it,
# isEmpty is called there, and the element is asked for as the Vector2 it is. What RayQueries counts
# besides is its start (64 bodies made, each with a shape, and the parameters). ArrayConversion still
# asks in every frame: the collections handed over. A number that grows is a fast path lost.
# handles: the handles on Godot's values and objects generated code had the host copy. lookups: the times
# it asked the engine for the object behind a handle. Neither grows with the frames of MoveNodes or of
# PerNodeProcess: a node's handle is copied by the host once, the first time it is shared (the host looks
# at what it is on), and the object behind it is asked for twice, after which it is read from the handle
# for as long as Godot frees nothing the host has found. Nor with the rays of RayQueries: the register the
# query's parameters are read into keeps its handle while the field holds the same object.
