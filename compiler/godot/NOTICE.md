`godot --dump-extension-api`). The class, method, property, signal and constant names it declares are
Godot's, renamed by the rules in `naming.py`.

The API description itself is not in this repository. To regenerate `godot.as` for a Godot version:

```bash
godot --headless --dump-extension-api
```

```bash
python3 compiler/godot/generate.py extension_api.json compiler/godot/godot.as compiler/godot/godot_names.txt
```
