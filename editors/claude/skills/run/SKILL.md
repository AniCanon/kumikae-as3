---
name: run
description: Run a Kumikae AS3 game locally in Godot or launch it on a simulator or emulator.
argument-hint: "<desktop|ios-simulator|android>"
---

From the game directory, invoke `"${CLAUDE_PLUGIN_ROOT}/bin/kumikae" run` with the requested arguments as separate, quoted values. Desktop Play is a foreground game process. Use background execution when the developer wants to keep playing. Report the selected target and launch result.
