---
name: run
description: Run a Kumikae AS3 game locally in Godot or launch it on a simulator, emulator or browser.
argument-hint: "<desktop|ios-simulator|android|web>"
---

From the game directory, invoke `"${CLAUDE_PLUGIN_ROOT}/bin/kumikae" run` with the requested arguments as separate, quoted values. Desktop Play and the Web preview server run in the foreground. Use background execution when the developer wants to keep playing. Report the selected target and launch result.
